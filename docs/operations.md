# Эксплуатация АВТОWAY

## Ежедневно / по cron

```powershell
# Проверка доступности БД и настройки почты
npm run monitor:check

# Резервная копия SQLite + PRAGMA integrity_check
npm run db:backup

# Проверка последней копии
npm run db:backup:check
```

Рекомендуемое расписание:

- backup — каждый день в 02:00;
- monitor:check — каждые 5 минут;
- проверка восстановления — раз в неделю на копии, не на рабочей БД.

## Мониторинг

Админка: `/admin/monitoring`.

Показывает:
- состояние БД и наличие SMTP-настроек;
- ошибки интерфейса, API и серверных маршрутов;
- список резервных копий;
- кнопку создания копии с проверкой целостности.

## E2E-проверки форм

```powershell
npm run test:e2e
```

Проверяются формы контактов, все четыре лендинга, вакансии, продажа, автоподбор и калькулятор аренды. Тестовые заявки автоматически удаляются после прогона.

## Контент лендингов

Админка: `/admin/landings`.

Хранится в таблице `service_landings`:
- SEO и Open Graph;
- первый экран;
- секции преимуществ/шагов/цен/направлений/аудиторий/сравнения;
- FAQ;
- CTA, тексты формы и sticky-кнопки.

Сид: `npm run db:seed:landings` (также входит в `npm run db:seed`).

## CRM

- `/admin/requests` — единый inbox;
- `/admin/clients` — история клиента по телефону;
- `/admin/tasks` — задачи и напоминания;
- CRM-поля заявки: ответственный, следующий контакт, причина отказа, внутренняя заметка, заметки и задачи.

Все CRM-данные хранятся в `lead_meta`, `lead_notes`, `lead_tasks`.
