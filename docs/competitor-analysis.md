# Анализ конкурента: pro-service.cc

> Дата: 27.10.2026
> Сайт: https://pro-service.cc — детейлинг-студия в Москве (с 2009)
> Цель: изучить фичи и UX, выбрать что перенести в АВТОWAY (avtoway.by)

---

## 1. Что это за сайт

Детейлинг и тюнинг студия в Москве. Услуги: защитная плёнка, полировка, керамика, химчистка салона, шумоизоляция, пошив/тюнинг салона, рестайлинг, дооснащение и переделка фар, аквапринт, удаление вмятин, кузовной ремонт, покраска дисков.

Позиционирование — «Внимание к каждой детали», акцент на реальных работах и клиентах.

## 3. Ключевые фичи (детально)

### 3.1 Калькулятор услуг (`/calculator/`)
Пошаговый мастер:
1. **Автомобиль** — выбор марки/модели (необязателен, без него показывается диапазон).
2. **Услуги** — выбор работ по названию и цене, кнопка «Что входит» раскрывает состав. Фильтр по направлению + поиск.
3. **Предварительный расчёт** — сумма выбранного, кнопка «Записаться».

Механики:
- Дедупликация: повторяющиеся работы не плюсуются дважды.
- Дисклеймер «Итог предварительный», услуги без цены считаются отдельно.
- Связка с формой заявки (итог передаётся в запись).

**Вывод для АВТОWAY:** идеально ложится на `RentCar.priceDay/price3Days/price7Days/priceMonth`. Калькулятор «рассчитай аренду»: авто → даты → срок → доп. опции → итог.

### 3.2 Навигация по задачам («С чего начнём?»)
Вместо плоского каталога — 4 задачи:
- «Купил новый авто» → защита, керамика, шумоизоляция
- «Хочу вернуть блеск» → полировка, детейлинг, удаление вмятин
- «Салон потерял вид» → химчистка, перешив, аквапринт
- «Хочу другой характер» → тюнинг, цветная плёнка, покраска дисков

Каждая задача — фото + набор услуг-ссылок.

**Вывод для АВТОWAY:** переделать `/services` по намерениям: «Арендовать на выходные», «Авто под такси», «Пригнать/купить из-за границы», «Осмотр перед покупкой».

### 3.3 Акции (`/akcii/`)
Карточки с «Выгода до 40 000 ₽», сезонные предложения («сентябрь — ноябрь 2026»), отдельная страница + блок на главной. Слаги-выводы, promo-медиа через API.

**Вывод:** модуль «Спецпредложения» со скидками на аренду.

### 3.4 Портфолио «Наши работы» (`/works/`)
- 154 проекта, фильтры по категории (6) и марке (40).
- Карточка: фото, категория, марка, название, описание, «Смотреть проект».
- Деталь проекта: meta-блок (локация/срок/стоимость/работы/автомобиль), «Задача и решение», «Состав работ», **«До/После»** (парные фото), «Детали крупным планом», «Другие проекты».
- Прозрачность цены: «Подтверждённая стоимость — 25 000 ₽».

**Вывод:** для сервиса/импорта/продажи — раздел «Наши работы» с фильтром по марке (уже есть FK `car_brands`/`car_models`).

### 3.5 Соц. доказательство
- **Отзывы Яндекс.Карт**: рейтинг 5.0, бейдж «Хорошее место» (2023–2026), скриншоты отзывов, ссылка на карточку, «проверено 13 октября 2026».
- **Клиенты-знаменитости**: GUF, Дубровский, Дорохов, Ярушин и др. — фото + авто + вид работ.

**Вывод:** интеграция Google/Яндекс-отзывов + «Наши клиенты» (таблица `Partner`).

### 3.6 Умная форма заявки
Поля: телефон, авто (необязательно), **способ связи (позвонить/Telegram)**, направление, описание (необязательно), **фото авто** (необязательно), юридические согласия (обработка данных + реклама).

**Вывод:** в форму АВТОWAY добавить «способ связи» (звонок/Telegram/WhatsApp/Viber) — прямое попадание в roadmap CRM (заявки из мессенджеров).

### 3.7 Подарочные сертификаты
Номинал от 30 000 ₽, электронный/бумажный, заявка менеджеру (без онлайн-оплаты), пошаговый процесс «Заявка → Согласование → Выдача».

**Вывод:** «Подари аренду авто на выходные» — выделит в нише аренды.

### 3.8 История «с 2009»
Таймлайн 7 этапов (фото прошлых мастерских), основатель, рабочие посты («без постановки»), соцсети.

**Вывод:** страница «О нас» с историей и людьми.

### 3.9 SEO-каркас
Полный `sitemap.xml` (все работы/услуги), `robots.txt` с правилами API (`Disallow: /api/`, `Allow: /api/public/...`), хлебные крошки на всех страницах, JSON-LD.

## 5. Технические наблюдения

- **Динамические изображения** через API (`/api/public/website-projects/promotion-media/<uuid>?v=<ts>`) — удобно для кэш-бастинга и контроля доступа.
- **Правовые страницы** — отдельные согласия на обработку данных и на рекламу (важно для РБ — Закон о персональных данных).
- **Хлебные крошки** на каждой странице — и навигация, и SEO.
- **«Показать ещё N»** — progressive disclosure в длинных списках (клиенты, марки).
- **Мультилокация** — 2 адреса с раздельными часами и телефонами (для АВТОWAY — если будет несколько точек).
