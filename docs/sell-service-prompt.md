## 1. Бизнес-задача и UX-концепция

Сейчас `/services/sell` попадает на полупустой generic-шаблон `/services/[slug]`. Нужно превратить `/services/sell` в **полноценную витрину проверенных автомобилей в продаже + страницу услуги комиссионной продажи / выкупа авто**.

Главные требования к UX и читабельности:
1. **Привычный и удобный фильтр как на av.by / abw.by** — пользователь за 5 секунд выбирает марку, модель, цену (в `$` или `BYN`), год, коробку, топливо, кузов, привод, пробег и сразу видит подходящие машины.
2. **Двойная индикация цены (USD + BYN)** — в Беларуси авторынок мыслит в долларах, а расчёты идут в BYN. Везде (в карточке каталога и на странице авто) показывай цену крупно в основной валюте и рядом мелким шрифтом — эквивалент во второй валюте по курсу НБРБ (`getUsdRate()`), плюс переключатель валюты в фильтре (`USD $` / `BYN р.`).
3. **Каждая машина — отдельная полноценная SEO-страница (`/services/sell/[slug]`)**, которую приятно читать с телефона и компьютера: чёткая типографика, сгруппированные характеристики без «каши», честный блок «Отчёт проверки АВТОWAY», разделённая по категориям комплектация и быстрая фотогалерея на 20–40 снимков.
4. **Два сценария конверсии**:
   - **Покупатель авто**: выбирает машину в каталоге → читает характеристики и отчёт → записывается на осмотр / тест-драйв / предлагает свою цену / трейд-ин.
   - **Продавец авто**: видит внизу (и в компактном баннере каталога) блок «Продадим ваш автомобиль быстро и дорого» → оставляет заявку на оценку/продажу своего авто.

## 2. Схема базы данных (`prisma/schema.prisma`)

Расширь связи в `CarBrand` и `CarModel` и добавь модели `SaleCar` и `SaleLead` (или `SaleRequest`):

```prisma
model SaleCar {
  id              String    @id @default(uuid())
  slug            String    @unique
  title           String    // Например: "BMW 5 серия G30 530i xDrive" (может формироваться автоматически или вручную)

  // Связь со справочниками марок и моделей
  brandId         String?   @map("brand_id")
  modelId         String?   @map("model_id")
  brandRel        CarBrand? @relation("SaleCarBrand", fields: [brandId], references: [id], onDelete: SetNull)
  modelRel        CarModel? @relation("SaleCarModel", fields: [modelId], references: [id], onDelete: SetNull)
  generation      String?   // Поколение / кузов, например "G30 (рестайлинг)" или "XV70"

  // Цена и условия сделки
  priceUsd        Int       @map("price_usd")          // Базовая цена в USD (например, 24500)
  priceByn        Int?      @map("price_byn")          // Фиксированная цена в BYN (если не задана — считается по курсу НБРБ)
  oldPriceUsd     Int?      @map("old_price_usd")      // Старая цена (для бейджа «Цена снижена»)
  isNegotiable    Boolean   @default(true) @map("is_negotiable") // Возможен торг
  allowExchange   Boolean   @default(false) @map("allow_exchange") // Возможен обмен / трейд-ин
  allowCredit     Boolean   @default(false) @map("allow_credit")   // Возможен кредит / лизинг

  // Основные технические характеристики (для фильтрации и таблицы)
  year            Int                                  // Год выпуска (например, 2020)
  mileageKm       Int       @map("mileage_km")         // Пробег в км (например, 84000)
  bodyType        String    @map("body_type")          // sedan | wagon | hatchback | liftback | suv | coupe | minivan | pickup | van
  transmission    String                               // auto | manual | robot | variator
  fuel            String                               // gasoline | diesel | gas-propane | hybrid | electric и т.д.
  engineVolume    Float?    @map("engine_volume")      // Объём в литрах, например 2.0 (null для электро)
  enginePowerHp   Int?      @map("engine_power_hp")    // Мощность, л.с. (например, 249)
  driveType       String    @map("drive_type")         // fwd (передний) | rwd (задний) | awd (полный)
  color           String?                              // Цвет кузова
  interiorMaterial String?  @map("interior_material")  // leather | fabric | alcantara | combined | eco-leather
  interiorColor   String?   @map("interior_color")     // dark | light | brown | combo
  steering        String    @default("left")           // left | right
  seats           Int?      @default(5)
  doors           Int?      @default(4)

  // История, документы и состояние
  condition       String    @default("used")           // used (с пробегом) | new (новый) | damaged (аварийный)
  ownersCount     String?   @map("owners_count")       // "1", "2", "3+"
  originCountry   String?   @map("origin_country")     // РБ, Европа, США, Корея, Китай, РФ
  customsCleared  Boolean   @default(true) @map("customs_cleared") // Растаможен
  vin             String?                              // Полный или маскированный VIN (например, WBA53************)
  vinVerified     Boolean   @default(false) @map("vin_verified")
  originalPaint   Boolean   @default(false) @map("original_paint") // В родной краске
  noAccidents     Boolean   @default(false) @map("no_accidents")   // Без ДТП
  serviceBook     Boolean   @default(false) @map("service_book")   // Сервисная история

  // Заключение эксперта АВТОWAY (ключевое УТП!)
  isInspected     Boolean   @default(true) @map("is_inspected")    // Проверено АВТОWAY
  expertSummary   String?   @map("expert_summary")                 // Короткий вердикт эксперта (2-4 предложения)
  bodyCheckNote   String?   @map("body_check_note")                // Кузов и ЛКП (толщиномер)
  techCheckNote   String?   @map("tech_check_note")                // Двигатель, КПП, подвеска, диагностика
  legalCheckNote  String?   @map("legal_check_note")               // Юридическая чистота (залоги, ограничения)
  diagnosticsPdf  String?   @map("diagnostics_pdf")                // Ссылка на файл/фото отчёта (опционально)

  // Комплектация, описание, медиа
  features        String?                              // JSON-массив или список опций через запятую
  customSpecs     String?   @map("custom_specs")       // JSON массив доп. характеристик [{ label, value }]
  description     String?                              // Подробное читабельное описание автомобиля
  mainPhoto       String?   @map("main_photo")
  photos          String?                              // JSON-массив или CSV до 40 URL фотографий в нужном порядке
  videoUrl        String?   @map("video_url")          // Ссылка на YouTube-обзор этого авто

  // Локация и контакты продавца/менеджера
  city            String    @default("Минск")
  contactName     String?   @map("contact_name")
  contactPhone    String?   @map("contact_phone")

  // Статус и публикация
  status          String    @default("available")      // available (В наличии) | reserved (В резерве) | sold (Продано) | draft (Черновик)
  isFeatured      Boolean   @default(false) @map("is_featured") // Закрепить в топе / спецпредложение
  isActive        Boolean   @default(true) @map("is_active")
  viewsCount      Int       @default(0) @map("views_count")
  sortOrder       Int       @default(0) @map("sort_order")

  // SEO
  seoTitle        String?   @map("seo_title")
  seoDescription  String?   @map("seo_description")

  createdAt       DateTime  @default(now()) @map("created_at")
  updatedAt       DateTime  @updatedAt @map("updated_at")
  requests        SaleRequest[]

  @@index([status, isActive, sortOrder])
  @@index([brandId, modelId])
  @@index([priceUsd])
  @@index([year])
  @@map("sale_cars")
}

model SaleRequest {
  id          String   @id @default(uuid())
  type        String   @default("buy") // "buy" (осмотр/покупка авто из каталога) | "trade_in" (обмен) | "sell_own" (продать своё авто через АВТОWAY)
  carId       String?  @map("car_id")
  car         SaleCar? @relation(fields: [carId], references: [id], onDelete: SetNull)
  clientName  String   @map("client_name")
  clientPhone String   @map("client_phone")
  carInfo     String?  @map("car_info") // Для "sell_own" или "trade_in": марка, модель, год, желаемая цена клиента
  offerPrice  Int?     @map("offer_price") // Если покупатель предлагает свою цену
  comment     String?
  status      String   @default("new") // new | in_progress | completed | rejected
  createdAt   DateTime @default(now()) @map("created_at")
  updatedAt   DateTime @updatedAt @map("updated_at")

  @@index([status, createdAt])
  @@index([carId])
  @@map("sale_requests")
}
```

### 3.1. Компактная шапка каталога (Hero-header)
Не делай огромный пустой баннер на весь экран — пользователь пришёл смотреть машины:

- Подзаголовок: «Каждый автомобиль прошёл комплексную диагностику кузова, технической части и юридической чистоты».
- Справа две аккуратные кнопки:
  - `Подобрать авто в каталоге ↓`
  - `Продать свой автомобиль` (якорь к форме комиссии/выкупа или модальное окно «Оценить и продать авто»).

### 3.2. Панель фильтров в стиле av.by / abw.by
Сделай продуманную, интуитивную панель фильтрации в карточке `bg-zinc-900/90 border border-zinc-800 rounded-2xl p-4 sm:p-6`:

1. **Первая строка (основные параметры — всегда видны):**
   - **Марка** (select с поиском или группировкой + количество машин у марки; при смене марки сбрасывается модель).
   - **Модель** (select, активен после выбора марки, подгружает модели выбранной марки).
   - **Поколение / кузов** (текст или select по доступным поколениям выбранной модели).
   - **Цена (от — до)** + **переключатель валюты `USD ($)` / `BYN (р.)`** прямо в заголовке поля цены. Если пользователь вводит диапазон в BYN — фильтр переводит его по курсу в USD (или фильтрует по расчётной цене).

2. **Вторая строка (технические параметры):**
   - **Год выпуска**: «От» — «До» (select от 1995 до текущего года).
   - **Коробка передач**: Все / Автомат (включая робот и вариатор, как на av.by!) / Механика / Точный выбор.
   - **Тип двигателя**: Бензин / Дизель / Газ / Гибрид / Электро.
   - **Объём двигателя, л**: «От» — «До» (от 1.0 до 6.0 л).

3. **Раскрывающийся блок «Все параметры» (по клику на «Расширенный фильтр»):**
   - **Тип кузова** (мультивыбор или чипсы с иконками: Седан, Кроссовер, Универсал, Хэтчбек, Минивэн, Купе и т.д.).
   - **Привод**: Передний / Задний / Полный.
   - **Пробег до, км**: быстрые пресеты или поле ввода.
   - **Быстрые чекбоксы-бейджи**:
     - `✓ Проверено АВТОWAY`
     - `✓ В родной краске`
     - `✓ Без ДТП`
     - `✓ Возможен обмен / трейд-ин`
     - `✓ Скрыть проданные`

4. **Нижняя панель управления фильтром:**
   - Активные фильтры в виде удаляемых тегов-чипсов (`BMW ×`, `до $25 000 ×`, `Автомат ×`).
   - Кнопка `Сбросить всё`.
   - Сортировка: `По умолчанию (рекомендуемые)` | `Сначала свежие` | `Сначала дешевле` | `Сначала дороже` | `Меньше пробег` | `Новее год`.
   - Переключатель вида карточек на десктопе: **Сетка (3 в ряд)** / **Горизонтальный список (как на av.by)**.
   - На мобильных фильтр сворачивается в удобную кнопку `Фильтры (активно: N)` с открытием bottom-sheet / модального окна и закреплённой кнопкой `Показать N авто`.
   - **Синхронизация с URL (`?brand=bmw&priceMax=25000&transmission=auto...`)** через `useRouter`/`useSearchParams`, чтобы фильтрами можно было делиться по ссылке и возвращаться кнопкой «Назад» без потери выбранных параметров.

### 3.3. Карточка автомобиля в списке
Каждая карточка должна читаться мгновенно, без визуального шума:
- **Фото-блок (соотношение 16:10 или 4:3):**
  - При наведении мыши на десктопе (hover-scrubbing как на av.by / auto.ru) — переключение между первыми 5 фото с тонкими индикаторами-полосками внизу фото; если фото больше 5 — на 5-м кадре плашка `+ ещё N фото`.
  - В левом верхнем углу бейджи: `В наличии` (зелёный), `В резерве` (жёлтый), `Продано` (серый) + бейдж `Проверено АВТОWAY` (красный/фирменный).
  - В правом нижнем углу иконка камеры со счётчиком всех фото (например, `📷 24`) и иконка `▶ Видео`, если есть видеообзор.
- **Информационный блок:**
  - Название: `Марка Модель Поколение` + `Год` (крупно, жирно, при наведении меняет цвет).
  - **Цена (как на av.by):**
    - Крупно: `68 900 р.` (BYN) и рядом заметно `≈ $21 500` (или наоборот в зависимости от выбранной валюты).
    - Если есть `oldPriceUsd` — зачёркнутая старая цена и зелёный бейдж `−$1 200`.
  - **Читабельная сводка характеристик в 2 строки / пилюли:**
    - `2020 г.` • `Автомат` • `2.0 л, Бензин (249 л.с.)`
    - `Седан` • `Полный привод` • `84 000 км`
  - **Преимущества одной строкой (теги):** `В родной краске` • `Без ДТП` • `Оригинал ПТС/сервисная книга` • `Обмен`.
  - Короткая цитата эксперта (1 строка с `line-clamp-1`, если заполнено `expertSummary`).
  - Нижняя строка: `📍 Минск` + кнопка `Подробнее →`.

### 3.4. Секция «Продать свой автомобиль через АВТОWAY» (внизу страницы каталога)
Для клиентов, которые зашли в раздел «Продажа авто», чтобы продать свою машину:
- 3 формата работы (понятные карточки):
  1. **Комиссионная продажа под ключ** — предпродажная подготовка, профессиональная фото/видеосъёмка (30+ фото), публикация на всех площадках, звонки, показы и оформление сделки.
  2. **Помощь в продаже без постановки на стоянку** — вы продолжаете ездить на своём авто, а мы берём на себя рекламу, переговоры и проверку покупателей.
  3. **Срочный выкуп / Трейд-ин** — честная оценка и быстрый расчёт в день обращения или зачёт в счёт выбранного авто из каталога.
- Компактная форма оценки авто: `Ваше имя`, `Телефон`, `Марка, модель и год авто`, `Желаемая цена ($)`, кнопка `Оценить моё авто` (отправляет в `/api/sell/requests` с `type: "sell_own"`).

## 6. Архитектура, API и безопасность

Соблюдай структуру проекта:
- **Доменный слой (`src/entities/sell/`):**
  - `sale-car.types.ts` — чистые TypeScript-интерфейсы (`SaleCar`, `SaleCarFilters`, `SaleRequest`, `CustomSpec`).
  - `sale-car.schema.ts` — Zod-схемы создания/обновления авто и валидации публичной заявки (`saleRequestSchema` с honeypot-полем `company`).
  - `sale-car.repository.ts` — интерфейс `SaleCarRepository`.
- **Инфраструктура (`src/infrastructure/persistence/sale-car.prisma.repository.ts`):**
  - Реализация `PrismaSaleCarRepository` и регистрация `"SaleCarRepository"` в `src/di/composition-root.ts`.
- **API routes (`src/app/api/sell/...`):**
  - `GET /api/sell` — список авто с фильтрацией и сортировкой (параметр `showAll=true` только с `requireAuth("sell.manage")`).
  - `POST /api/sell` — создание авто (`requireAuth("sell.manage")` + `createAuditLog`).
  - `GET / PATCH / DELETE /api/sell/[id]` — получение, обновление и удаление авто (`requireAuth("sell.manage")` + `createAuditLog`).
  - `GET / POST /api/sell/requests` и `PATCH / DELETE /api/sell/requests/[id]` — публичная отправка заявки (с валидацией Zod, honeypot и rate-limit в `src/proxy.ts` на `/api/sell/requests`) и управление заявками в админке (`requireAuth("sell.manage")`).

  - Добавь в сид 4–6 реалистичных разноплановых автомобилей в продаже (например, BMW 5 G30, Toyota Camry XV70, Volkswagen Passat B8, Geely Monjaro, Audi A6 C8, Tesla Model 3) с заполненными характеристиками, комплектацией и отчётом эксперта, чтобы каталог и фильтры сразу можно было протестировать вживую.

## 7. Критерии приёмки (Definition of Done)

1. На `/services/sell` работает полноценный каталог с фильтрами (марка, модель, цена USD/BYN, год, КПП, топливо, объём, кузов, привод, пробег, чекбоксы состояния), сортировкой и переключением вида (сетка / список).

6. Все проверки проходят без ошибок:
   - `npm run lint` (0 errors)
   - `npm run typecheck`
   - `npx vitest run` (плюс юнит-тесты на Zod-схемы и фильтрацию каталога продажи)
