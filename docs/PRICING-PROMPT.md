# Промт: ценообразование и калькулятор аренды авто (Минск, avtoway.by)

> Готовый промт для AI-агента/разработчика. Вставлять целиком.
> Контекст рынка и цифры собраны по действующим сайтам проката Минска (сентябрь–октябрь 2026).

---

## 0. Роль и задача

Ты — senior full-stack разработчик (Next.js App Router + TypeScript + Prisma + PostgreSQL) и одновременно продукт-аналитик автопроката.

Задача: привести ценообразование раздела «Аренда авто» к рыночной модели Минска и реализовать прозрачный онлайн-калькулятор, который считает **итоговую стоимость до звонка менеджера**.

Работай в существующем проекте, не ломая текущие API и структуру. Деньги — **целые числа в BYN** (никаких float в БД). Все цены на сайте — «включительно, BYN», НДС/налоги уже внутри.

Обязательные свойства результата:
1. Клиент видит цену за сутки по периодам (1–2 / 3–7 / 8–14 / 15–30 / 31+).
2. Калькулятор показывает полную смету: аренда + скидка + доп. услуги + доставка + залог (отдельно).
3. Все коэффициенты, залоги, лимиты пробега и допы редактируются в админке, без деплоя.
4. Никаких «скрытых платежей»: залог, топливо, мойка, перепробег, просрочка — явно на экране и в договоре.
5. Логика покрыта unit-тестами (минимум 20 кейсов, см. §14).

## 1. Термины

- **Сутки аренды** — 24 часа с момента выдачи. Неполные сутки = полные.
- **Grace-период возврата** — 60 минут бесплатно (настраивается).
- **Базовый тариф (`priceDay`)** — цена за 1–2 суток.
- **Период** — ступень по количеству суток, к которой применяется скидка.
- **Залог (депозит)** — возвращаемая страховка ответственности, **не входит** в выручку и в «Итого к оплате», показывается отдельной строкой.
- **Лимит пробега** — включённые км, суммируются за весь срок аренды (не «в день»).
- **Перепробег** — оплата за каждые полные/неполные 100 км сверх лимита.
- **Франшиза** — сумма, в пределах которой ущерб покрывает арендатор (обычно = залогу).

## 3. Тарифная сетка (ядро ценообразования)

### 3.1. Ступени и скидки по умолчанию

| Период | Скидка от `priceDay` | Коэффициент | Смысл |
|--------|----------------------|-------------|-------|
| 1–2 суток | 0% | 1.00 | базовый тариф |
| 3–7 суток | 10% | 0.90 | «на выходные/короткая поездка» |
| 8–14 суток | 17% | 0.83 | неделя+ |
| 15–30 суток | 25% | 0.75 | полмесяца |
| 31+ суток | 32% | 0.68 | долгосрок, дальше — индивидуально |

Обоснование: рынок Минска даёт ступени 1–3 / 4–7 / 8–14 / 15–30 с шагом 5–10% и суммарно 20–30% к месяцу. Текущие значения в проекте (20/25/30) слишком агрессивны для эконом-класса и «съедают» маржу.

Все пять коэффициентов — **настройки в админке** (`RentSettings`), не хардкод.

### 3.2. Формула

```
days        = max(1, ceil((endAt - startAt) / 24h))       // неполные сутки = полные
tier        = tierOf(days)                                 // 1–2 / 3–7 / 8–14 / 15–30 / 31+
perDay      = round(priceDay * (1 - discount[tier]))       // или priceTier[tier], если задан явно
rental      = perDay * days
```

Правила округления:
- `perDay` — до целого BYN (математически).
- `rental` — до целого BYN.
- В UI показывать `perDay` и `days`, чтобы клиент мог проверить.

### 3.3. Явные цены по периодам (override)

Для части авто задавать цены руками (акции, старые машины). Поля в `RentCar`:
- `priceDay` (1–2),
- `price3Days` (за сутки в периоде 3–7, опционально),
- `price7Days` (**за неделю целиком**, опционально; если задано — имеет приоритет над формулой на 7 суток),
- `priceMonth` (за 30 суток целиком, опционально),
- `priceDayTaxi` (для режима «под такси»).

Приоритет: явное поле → формула со скидкой → `null` («по запросу»).

### 3.4. Акция «7-й день бесплатно»

Альтернатива недельной скидке. Если включена: при `days >= 7` клиент платит `days - 1` суток.
**Не суммируется** со ступенчатой скидкой: система считает оба варианта и выбирает **выгодный клиенту**, в смете пишет «выгода по акции — X BYN». Так же для «каждый 15-й день бесплатно» на долгосроке.

## 5. Скидки и наценки

Порядок применения (сверху вниз), каждая — опциональна:

1. **Ступенчатая скидка по сроку** (§3.1) — всегда.
2. **Долгосрок 31+** — вместо ступени 15–30, либо индивидуальная цена (`priceMonth`).
3. **Промокод** (`promo`) — % или фикс, задаётся в админке, срок действия, лимит использований.
4. **Постоянный клиент** — 5–10% по номеру телефона/аккаунту (только если есть авторизация).
5. **Раннее бронирование** — 5% при брони за 14+ дней (опционально, выключено по умолчанию).
6. **Наценки за сезон/праздники** — коэффициент 1.1–1.3 на заданные даты (Новый год, майские, свадебные даты). По умолчанию выключено, чтобы не пугать клиента.
7. **Выходные** — для спорт/премиум +10% (пт–вс). Выключено по умолчанию.

Правила:
- Скидки **не суммируются мультипликативно**: применяется максимальная из применимых, кроме промокода (промокод суммируется с одной ступенчатой).
- Все скидки показывать отдельной строкой «Скидка −X BYN», а не «прятать» в цене.
- Итог никогда не ниже `floorPrice` класса (параметр, по умолчанию 50% от `priceDay`).

## 6. Пробег

| Параметр | Значение по умолчанию |
|----------|------------------------|
| Лимит | 300 км/сутки (эконом/комфорт), 350 км/сутки (бизнес/SUV/минивэн), 250 км/сутки (премиум/спорт/электро) |
| Суммирование | за весь срок: `limit = kmPerDay × days` |
| Перепробег | 20 BYN за каждые полные/неполные 100 км |
| Долгосрок 31+ | опция «безлимит» +15–25% к тарифу |

```ts
const limit = car.kmPerDay * days;
const over  = Math.max(0, odometerEnd - odometerStart - limit);
const overCost = Math.ceil(over / 100) * car.kmOverPrice; // 20 BYN
```

В калькуляторе: подсказка «включено N км, дальше 20 BYN/100 км». Пробег фактический вводит менеджер при возврате — калькулятор показывает только лимит и справочную ставку.

## 10. Требования к арендатору и доплаты

| Параметр | Эконом/Комфорт | Бизнес/Премиум | Грузовой |
|----------|----------------|----------------|----------|
| Возраст | 21+ (в идеале 22+) | 23–25+ | 25+ |
| Стаж | 2 года | 5 лет | 5 лет + категория C |
| Документы | паспорт + ВУ | паспорт + ВУ | паспорт + ВУ C |

Доплаты (опционально, выключено по умолчанию):
- «Молодой водитель» 21–24 года: +10 BYN/сутки или +15%.
- Стаж 1–2 года: +10% (или отказ для премиума).
- Иностранное ВУ: без доплаты, но нужен перевод/МВУ — только текст-предупреждение.

Валидация в калькуляторе: дата рождения → возраст на дату выдачи; стаж → блокировка с понятным текстом и кнопкой «Связаться с менеджером».

## 11. Выезд за границу

- Разрешено: РБ, РФ, ЕС (кроме Украины — по правилам перевозчика).
- Доплата: **+10 BYN/сутки** (рынок).
- «Зелёная карта» — **не включена**, оформляет арендатор; в смете — информационная строка 0 BYN.
- Отдельный пункт договора + согласование менеджером; в калькуляторе чекбокс «выезд за границу» → +10/сутки и предупреждение.

## 12. Штрафы, просрочка, топливо, мойка

| Ситуация | Правило |
|----------|---------|
| Возврат в течение 60 мин после срока | бесплатно |
| 60 мин – 4 часа | +1 сутки (по тарифу текущего периода) |
| Более 4 часов | +1 сутки за каждые начатые 24 часа |
| Более 24 часов без связи | договор → угон/розыск (текст в договоре) |
| Топливо меньше, чем при выдаче | дозаправка по чеку + 10% + 10 BYN сервис |
| Топливо больше | не компенсируется (политика «полный бак») |
| Грязный салон/кузов | 20–30 BYN мойка |
| Курение/вейп | 100–200 BYN |
| Штрафы ПДД | оплачивает арендатор по факту |
| ДТП без справки ГАИ | полная материальная ответственность (текст) |
| Досрочный возврат | пересчёт по фактическому сроку (скидка пересчитывается), остаток возвращается со следующих суток |
| Отмена брони | бесплатно за 24 ч, позже — 1 сутки удержания |
| Продление | только по согласованию, оплата до окончания срока |

Все суммы — настройки в `RentSettings`, чтобы менять без релиза.

## 13. Итоговая смета (что видит клиент)

```
Аренда: Kia Rio · 4 суток × 99 BYN            = 396 BYN
Скидка за срок (10%)                          уже в цене (−44 BYN)
Доп. опции:
  Детское кресло (5 из 4 дней, потолок)       = 0 BYN
  Доставка в аэропорт MSQ                     = 70 BYN
Итого к оплате                                = 466 BYN
Залог (возвращается)                          = 300 BYN
Включено: КАСКО, ОСАГО, 1 200 км, мойка перед выдачей
Не включено: топливо, платные парковки, штрафы, «Зелёная карта»
```

Требования к выводу:
- Три блока: **К оплате**, **Залог**, **Что входит / не входит**.
- Кнопка «Забронировать» → заявка в `RentRequest` со снимком расчёта (JSON: тариф, дни, скидка, допы, доставка, залог, лимит км).
- PDF/печать сметы (опционально, но сильно повышает конверсию).
- Дисклеймер: «Предварительный расчёт. Финальную стоимость подтверждает менеджер».

## 14. Тест-кейсы (обязательны)

1. 1 сутки, эконом 70 → 70.
2. 2 суток, 70 → 140.
3. 3 суток, 100 → 270 (10%).
4. 7 суток, 100 → 630 (10%).
5. 8 суток, 100 → 664 (17%, `round(83)=83`).
6. 14 суток, 100 → 1162.
7. 15 суток, 100 → 1125 (25%).
8. 30 суток, 100 → 2250.
9. 31 сутки, 100 → 2108 (32%).
10. 4 суток + `price7Days = 600` → 600 имеет приоритет только при 7 днях, при 4 — формула.
11. Акция «7-й день бесплатно» vs скидка 10% → выбирается выгодное (6×100=600).
12. `price3Days = 90` (за сутки) при 5 днях → 450.
13. Перепробег: лимит 1200, факт 1350 → 2×20 = 40.
14. Перепробег 1201 → 1×20 = 20 (неполные 100 км = 100).
15. Просрочка 90 минут → +1 сутки.
16. Просрочка 30 минут → 0.
17. Досрочный возврат 10 → 6 дней: пересчёт по 3–7 (10%), возврат разницы.
18. Промокод 5% + ступень 10% → скидка 15% (только эта пара суммируется).
19. Промокод больше ступени → берётся промокод.
20. Доставка бесплатна от 7 суток: 7 дней → 0, 6 дней → 70.
21. Возраст 20 → блок, текст.
22. Залог не входит в «Итого к оплате».
23. Округление: `priceDay=115`, 17% → 95.45 → 95.
24. Минимум 1 сутки: 3 часа → 1 сутки.
25. Високосный переход/переход через полночь — корректное число суток.

## 16. API

```
GET  /api/rent                      // ?class=&brand=&fuel=&transmission=&seats=&priceMax=
GET  /api/rent/classes
GET  /api/rent/extras
GET  /api/rent/delivery-zones
GET  /api/rent/settings
POST /api/rent/quote                // { carId, startDate, endDate, extras[], zoneFrom, zoneTo, abroad, promo }
POST /api/rent/requests             // сохранить снимок расчёта
POST /api/rent/promo/validate       // { code, days, amount }
```

`POST /api/rent/quote` — **единственный источник истины** для цены. Клиентский калькулятор вызывает его (debounce 300 мс) и рисует ответ; дублирующая логика на клиенте допустима только для мгновенного превью, но итог всегда с сервера.

Ответ `quote`:
```json
{
  "ok": true,
  "data": {
    "days": 4, "tier": "3-7", "perDay": 99,
    "rental": 396, "discount": 44, "promoDiscount": 0,
    "extras": [{ "slug": "child-seat", "amount": 0, "free": true }],
    "delivery": 70, "total": 466, "deposit": 300,
    "kmLimit": 1200, "kmOverPrice": 20,
    "included": ["КАСКО", "ОСАГО", "мойка"],
    "excluded": ["топливо", "парковки", "штрафы"],
    "warnings": []
  }
}
```

Валидация: даты в будущем, `end > start`, `days <= maxDays`, авто активно и не забронировано (`bookedUntil`), возраст/стаж, класс доступен.

## 17. UI/UX калькулятора (пошагово)

1. **Класс/авто** — горизонтальные карточки с ценой «от», фильтры (класс, КПП, топливо, места, цена).
2. **Даты** — date range, автоподсчёт суток, подсказка «выгоднее на 3 дня: −10%».
3. **Получение/возврат** — офис / адрес в МКАД / вокзал / аэропорт / другой город; разные места → +доставка.
4. **Доп. опции** — чекбоксы с ценой и типом («за сутки» / «разово»); бесплатные помечены.
5. **Данные** — имя, телефон, email, дата рождения, стаж, промокод, чекбокс «выезд за границу».
6. **Смета** (sticky справа) — обновляется сразу, breakdown, залог, лимит км, что входит/не входит.
7. **Отправка** — заявка, экран «Заявка отправлена», дубль в Telegram/на почту (уже есть SMTP).

Мобильная версия: смета — внизу экрана фиксированной панелью «Итого 466 BYN · Забронировать».

Микротексты:
- «Цены указаны за сутки и зависят от срока. Чем дольше — тем дешевле.»
- «Залог возвращается после аренды. Он не входит в стоимость.»
- «Лимит 300 км/сутки суммируется за весь срок.»
- «КАСКО и ОСАГО уже в цене.»
- «Бронирование бесплатное, отмена за 24 часа — без штрафа.»

## 21. Ограничения и антипаттерны

- Не хранить деньги во float. Только Int BYN (при необходимости — копейки, но не в этом проекте).
- Не считать цену только на клиенте — серверный `quote` обязателен.
- Не смешивать залог с оплатой аренды.
- Не показывать «0 BYN» вместо «по запросу».
- Не делать скидку больше 40% без промокода.
- Не ломать режим «под такси» (`price7Days`, `priceDayTaxi`, кратность неделям).
- Не забывать про уже существующие `RentRequest`, `RentCarHistory`, `RentCarCondition` — расширять, не переписывать.
- Юридически: цены — публичная оферта, но с оговоркой «не является окончательной до подтверждения менеджером»; залог and франшиза — в договоре.
