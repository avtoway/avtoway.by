# Безопасность АВТОВЕЙ

## Как сообщить об уязвимости

Пишите на `info@avtoway.by` с темой «Security». Не публикуйте детали публично до исправления.

## Что реализовано

- **Пароли:** bcrypt, минимальная длина 10 символов, обязательные буквы и цифры.
- **Сессии:** HMAC-SHA256, `timingSafeEqual`, `httpOnly` + `sameSite=lax` + `secure` в production, срок 24 часа.
- **Секреты:** fail-closed — без `AUTH_SECRET` и `ENCRYPTION_KEY` production не запускается.
- **Шифрование:** SMTP/IMAP-пароли в AES-256-GCM.
- **RBAC:** роли и права, проверка на уровне proxy, API и меню.
- **Аудит:** журнал действий пользователей.
- **Загрузка файлов:** проверка magic bytes, запрет SVG, перекодирование через sharp (убивает полиглоты), лимит 10 МБ.
- **Формы:** rate limit, honeypot, серверная валидация Zod.
- **Цены:** пересчитываются на сервере, клиентские суммы игнорируются.
- **CSRF:** проверка `Origin` для мутирующих запросов в proxy + `sameSite=lax`.
- **Заголовки:** CSP, HSTS (prod), `X-Frame-Options: DENY`, `nosniff`, Referrer-Policy, Permissions-Policy.
- **Счётчики:** rate limit на показы и клики рекламы.
- **Почта:** DOMPurify для HTML входящих писем.
- **Зависимости:** `npm audit --omit=dev` — 0 уязвимостей, Dependabot включён.

## Чек-лист перед продакшеном

- [ ] Сменить пароль `admin` и все демо-пароли.
- [ ] Задать боевые `AUTH_SECRET` и `ENCRYPTION_KEY` (64 hex-символа).
- [ ] Включить HTTPS и убедиться, что HSTS отдаётся.
- [ ] Проверить CSP в консоли браузера на всех ключевых страницах.
- [ ] Настроить резервное копирование **вне** сервера и проверить восстановление.
- [ ] Включить 2FA для админки (план) или ограничить доступ по IP/VPN.
- [ ] Настроить внешний uptime-мониторинг и Sentry.
- [ ] Ограничить SSH и обновлять сервер.

## Известные ограничения

- Rate limit хранится в памяти процесса — при нескольких инстансах нужен Redis.
- Нет 2FA и мгновенного отзыва сессий: после смены прав сотрудник должен выйти и войти заново.
- Нет WAF: рекомендуется Cloudflare перед сайтом.

## Доступ к админке по хосту

`/admin` открывается только на локальных адресах (`localhost`, `127.0.0.1`), на домене из `NEXT_PUBLIC_SITE_URL` и на хостах из `ADMIN_ALLOWED_HOSTS` (через запятую). Любой другой хост — публичные туннели (bore.pub, trycloudflare, ngrok, localhost.run), IP в локальной сети — получает редирект на главную. Это защищает пароль администратора при демонстрации сайта по временной ссылке. Логика: `src/shared/lib/admin-host.ts`, тесты: `tests/admin-host.test.ts`.
